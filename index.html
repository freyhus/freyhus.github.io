Vids Made Easy

A personal tool for making and publishing YouTube Shorts.

What it does

  • Finds which topics are popular on YouTube Shorts, using public YouTube data.
  • Turns a short script into a vertical video with narration, stock footage and captions.
  • With the channel owner's permission, uploads the finished videos to their own YouTube channel and reads that channel's YouTube Analytics to learn which videos work best.

Vids Made Easy uses YouTube API Services. It runs on the owner's own computer and is not a public service.
